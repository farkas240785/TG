# 🏛️ Тигель & Горн - Литейно-кузнечная мануфактура

## 📋 О проекте

Полнофункциональный веб-сайт литейно-кузнечной мануфактуры "Тигель & Горн", специализирующейся на реставрации исторической фурнитуры для объектов культурного наследия (ОКН) в Санкт-Петербурге и Чебоксарах.

## 🎯 Основные возможности

### Публичная часть сайта

#### 🏠 Главная страница
- Hero-секция с атмосферным изображением исторической мануфактуры
- Блок статистики (12+ лет, 47 объектов, 4 марки сплавов, 100% спектрометрия)
- Два блока "Тигель" и "Горн" с изображениями
- Интерактивный блок каталога с разделением на кованые и латунные изделия
- Галерея избранных проектов
- Секция "Обсудить проект" с формой
- Блок благодарственных писем

#### 📦 Каталог изделий
**Продвинутая система навигации:**
- Хлебные крошки для отслеживания пути
- Навигационные табы с счётчиками товаров
- Фильтры по категориям и подкатегориям
- Локальный поиск по каталогу
- Сортировка (по умолчанию, по названию, по артикулу)
- Переключение вида (сетка/список)
- Группировка товаров по подкатегориям

**Структура каталога:**

**🔨 Кованые изделия (10 товаров):**
- Вид 1: Оконная фурнитура и приборы
  - Подвид 1.1: Запирающие механизмы (кремоны, шпингалеты, завертки)
  - Подвид 1.2: Опорные и связующие элементы (жиковины)
  - Подвид 1.3: Элементы фиксации (крючки, гребенки)
- Вид 2: Дверная фурнитура и приборы
  - Подвид 2.1: Дверные навесы (жиковины, петли)
  - Подвид 2.2: Приводы запорных механизмов (ручки-кольца, скобы)
  - Подвид 2.3: Замки и ключевины (накладки прорезные)
  - Подвид 2.4: Вспомогательные запорные элементы (засовы)

**✨ Латунная фурнитура (5 товаров):**
- Оконные латунные приборы (кремоны, задвижки, фиксаторы)
- Дверные латунные приборы (ручки, кнобы, засовы, ключевины)
- Петли и навесы (карточные, ввертные, скрытые)
- Мебельные и интерьерные элементы (ручки, декор, каминные приборы)
- Архитектурная фурнитура (решётки, ковродержатели, кронштейны)

#### 🏛️ Проекты
