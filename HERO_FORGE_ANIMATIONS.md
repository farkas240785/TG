# 🔨 HERO-анимации - Эффекты кузнечной мастерской

## 📋 Обзор

HERO-секция содержит многослойную анимацию, имитирующую атмосферу работающей литейно-кузнечной мануфактуры с эффектами ковки, литья металла, искр и дыма.

**Важно:** Из-за ограничений API генерации изображений, анимация создана с помощью CSS-эффектов, которые передают атмосферу работы мастеров без использования изображений людей.

---

## 🎨 Структура анимаций

### 1. **Расплавленный металл** (`.hero-molten-metal`)

**Эффект:** Имитация литья расплавленной латуни и движения металла в тигле

**Технические детали:**
- 5 радиальных градиентов с золотистыми, бронзовыми и медными тонами
- Анимация `molten-flow` (12 секунд) - плавное движение градиентов
- Анимация `molten-pour` (8 секунд) - эффект литья металла
- Размытие `blur(60px)` для создания эффекта жидкости
- Дополнительные слои через `::before` и `::after`

**Визуальные элементы:**
- Основной слой: движение теплых градиентов с вращением
- `::before`: капли расплавленного металла с эффектом стекания
- `::after`: волны металла с рябью на поверхности

**Цветовая палитра:**
- `rgba(232, 197, 71, 0.5)` - яркий золотистый
- `rgba(212, 160, 23, 0.45)` - насыщенный золотистый
- `rgba(184, 134, 11, 0.4)` - бронзовый
- `rgba(196, 90, 60, 0.35)` - медный
- `rgba(240, 150, 80, 0.3)` - оранжевый

---

### 2. **Искры от кузнечных работ** (`.hero-sparks`)

**Эффект:** Множественные яркие искры, летящие от ударов молота по раскаленному металлу

**Технические детали:**
- 15 радиальных градиентов разного размера (2-4px)
- Анимация `sparks-fly` (4 секунды) - основное движение
- Анимация `sparks-burst` (2 секунды) - эффект взрыва искр
- Режим наложения `mix-blend-mode: screen` для яркости
- Дополнительный слой через `::before` с 6 градиентами
- Анимация `sparks-flicker` (1.5 секунды) - мерцание

**Визуальные элементы:**
- Основной слой: основные искры с движением и взрывами
- `::before`: вторичные искры с другим timing и мерцанием

**Цветовая палитра:**
- `rgba(255, 223, 100, 1)` - ярко-золотые искры
- `rgba(240, 190, 50, 1)` - оранжево-золотые
- `rgba(255, 235, 150, 1)` - белые горячие искры
- `rgba(220, 120, 80, 0.95)` - красно-оранжевые
- `rgba(255, 240, 180, 1)` - самые яркие белые

---

### 3. **Свечение горна** (`.hero-forge-glow`)

**Эффект:** Пульсирующее теплое свечение, имитирующее жар от кузнечного горна с ударами молота

**Технические детали:**
- 3 радиальных градиента с разными позициями
- Анимация `forge-pulse` (2 секунды) - пульсация свечения
- Анимация `hammer-strike` (3 секунды) - эффект ударов молота
- Режим наложения `mix-blend-mode: screen`
- Дополнительные слои через `::before` и `::after` с волнами жара

**Визуальные элементы:**
- Основной слой: пульсирующее свечение с вращением и ударами
- `::before`: расходящиеся волны жара (анимация `heat-waves`, 2.5 секунды)
- `::after`: вторичные волны жара с задержкой 1.25 секунды

**Цветовая палитра:**
- `rgba(220, 120, 80, 0.6)` - яркий оранжево-красный жар
- `rgba(240, 180, 60, 0.5)` - насыщенное золотистое свечение
- `rgba(220, 160, 40, 0.45)` - теплое бронзовое сияние
- `rgba(240, 150, 80, 0.6)` - волны жара
- `rgba(255, 180, 100, 0.5)` - вторичные волны

---

### 4. **Дым и пар** (`.hero-smoke`)

**Эффект:** Полупрозрачные слои дыма, поднимающегося от кузнечных работ

**Технические детали:**
- 5 радиальных градиентов с серыми тонами
- Анимация `smoke-rise` (18 секунд) - подъем дыма
- Анимация `smoke-swirl` (25 секунд) - вихревое движение
- Размытие `blur(35px)` для мягкости
- Дополнительный слой через `::before` с 4 градиентами
- Анимация `smoke-drift` (22 секунды) - дрейф дыма
- Анимация `smoke-expand` (30 секунд) - расширение дыма

**Визуальные элементы:**
- Основной слой: поднимающийся дым с вихревым движением
- `::before`: дрейфующий и расширяющийся дым

**Цветовая палитра:**
- `rgba(150, 140, 130, 0.3)` - светло-серый дым
- `rgba(140, 130, 120, 0.25)` - серый дым
- `rgba(120, 110, 100, 0.22)` - темный дым
- `rgba(160, 150, 140, 0.2)` - дополнительный светлый дым
- `rgba(170, 160, 150, 0.2)` - еще один слой дыма

## 🎭 Ключевые кадры анимаций

### `molten-flow` (12s)
Движение градиентов расплавленного металла с изменением прозрачности, масштаба и легким вращением. Создает эффект текучести металла в тигле.

### `molten-pour` (8s)
Эффект литья расплавленного металла с изменением позиции градиентов и яркости. Имитирует процесс pouring металла из тигля.

### `metal-drops` (8s)
Вертикальное движение капель металла с изменением масштаба и прозрачности. Создает эффект падающих капель расплавленного металла.

### `metal-drip` (12s)
Эффект стекания капель металла вниз. Имитирует процесс стекания расплавленного металла.

### `metal-waves` (10s)
Движение волн металла по диагонали с изменением масштаба и вращением. Создает эффект ряби на поверхности расплавленного металла.

### `metal-ripple` (6s)
Эффект ряби на поверхности металла с изменением размытия и яркости. Имитирует колебания поверхности расплавленного металла.

### `sparks-fly` (4s)
Движение искр по диагонали с изменением прозрачности и масштаба. Создает эффект летящих искр от ударов молота.

### `sparks-burst` (2s)
Эффект взрыва искр с резким изменением масштаба и позиции. Имитирует момент удара молота по раскаленному металлу.

### `sparks-secondary` (7s)
Вторичное движение искр с другим timing и позициями. Создает дополнительные слои искр для большей реалистичности.

### `sparks-flicker` (1.5s)
Мерцание вторичных искр с изменением яркости и контраста. Имитирует случайное мерцание искр.

### `forge-pulse` (2s)
Пульсация свечения горна с вращением, изменением прозрачности и яркости. Создает эффект живого огня в горне.

### `hammer-strike` (3s)
Эффект ударов молота с резким изменением яркости и контраста. Имитирует моменты ударов молота по металлу.

### `heat-waves` (2.5s)
Расходящиеся волны жара от центра горна с изменением размера, прозрачности и размытия. Создает эффект теплового излучения от горна.

### `smoke-rise` (18s)
Поднимающийся дым с вращением, изменением масштаба и прозрачности. Имитирует подъем дыма от кузнечных работ.

### `smoke-swirl` (25s)
Вихревое движение дыма с изменением позиций градиентов. Создает эффект завихрений дыма.

### `smoke-drift` (22s)
Дрейфующий дым с горизонтальным и вертикальным движением, изменением масштаба. Имитирует движение дыма в воздухе.

### `smoke-expand` (30s)
Расширение дыма с изменением позиций градиентов и прозрачности. Создает эффект расширения дымового облака.

## ⚡ Производительность

### Оптимизации:
- Использование `transform` и `opacity` для анимаций (GPU-ускорение)
- `will-change` не используется (браузер оптимизирует автоматически)
- Размытие через `filter: blur()` (эффективно для фоновых элементов)
- `mix-blend-mode: screen` для ярких эффектов (быстрее чем `overlay`)
- Множественные анимации на одном элементе для синхронизации

### Размер CSS:
- Добавлено ~25KB CSS для анимаций
- Общий размер CSS: 50.02 KB (gzip: 9.79 KB)

## 🔧 Настройка анимаций

### Изменение скорости:
```css
/* Ускорить движение металла */
.hero-molten-metal {
  animation: molten-flow 8s ease-in-out infinite; /* было 12s */
}

/* Замедлить дым */
.hero-smoke {
  animation: smoke-rise 30s ease-in-out infinite; /* было 18s */
}

/* Ускорить искры */
.hero-sparks {
  animation: sparks-fly 3s linear infinite; /* было 4s */
}
```

### Изменение интенсивности:
```css
/* Более яркие искры */
.hero-sparks {
  opacity: 1;
  /* Добавить больше точек в background-image */
}

/* Более заметное свечение горна */
.hero-forge-glow {
  background: radial-gradient(circle at 50% 50%, rgba(255, 150, 80, 0.7) 0%, transparent 60%);
}

/* Более густой дым */
.hero-smoke {
  opacity: 0.9;
}
```

### Отключение анимаций:
```css

@media (prefers-reduced-motion: reduce) {
  .hero-molten-metal,
  .hero-sparks,
  .hero-forge-glow,
  .hero-smoke {
    animation: none;
  }
}
```

## 🎬 Описание сцен

### Сцена 1: Ковка железа
Анимация искр с эффектом `sparks-burst` имитирует моменты ударов молота по раскаленному металлу. Пульсация свечения горна с `hammer-strike` создает эффект тепла от ударов. Дым поднимается от раскаленного металла.

### Сцена 2: Литье латуни
Анимация `molten-pour` имитирует процесс литья расплавленной латуни из тигля. Капли металла (`metal-drops` и `metal-drip`) создают эффект стекания металла. Волны и рябь (`metal-waves` и `metal-ripple`) показывают движение расплавленного металла.

### Сцена 3: Работа горна
Пульсирующее свечение (`forge-pulse`) и тепловые волны (`heat-waves`) создают эффект работающего горна. Дым поднимается и вихрится (`smoke-rise` и `smoke-swirl`), создавая атмосферу мастерской.
