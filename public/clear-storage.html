🔧 Очистка localStorage

Проблема: HERO-изображение не меняется, потому что старые данные сохраняются в localStorage браузера.

Решение: Очистите localStorage, чтобы загрузить новые значения по умолчанию.

📋 Что будет очищено:

  • site_content - весь контент сайта (включая HERO-изображение)
  • auth_user - данные авторизации (если есть)
  • tg_project_folder - папка проекта (если есть)

После очистки: Сайт загрузит новые значения по умолчанию из defaultContent.

💡 Альтернативный способ:

Откройте консоль браузера (F12) и выполните:

localStorage.clear()

Затем перезагрузите страницу.
