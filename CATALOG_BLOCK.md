# 🎨 Блок каталога на главной странице

## 📋 Описание

Блок каталога на главной странице представляет собой интерактивное изображение мастерской, разделённое на две кликабельные половины:

- **Левая половина** → Переход в каталог кованых изделий
- **Правая половина** → Переход в каталог латунной фурнитуры

## 🖼️ Визуальное оформление

### Изображение
- **Источник:** `https://image.qwenlm.ai/generated-images/17ae56f4-9a35-405b-b383-ac5714b0e0d8/_result.png`
- **Размер:** 1600×800 px (соотношение 2:1)
- **Стиль:** Реал-лайф фотография мастерской с инструментами
- **Эффект:** Тёмный overlay (70% непрозрачности)

### Разделитель
- **Вертикальная линия** по центру изображения
- **Цвет:** Золотой (`var(--c-gold)`)
- **Толщина:** 4px (1px на мобильных)

### Оверлей
- **Цвет:** `rgba(8, 7, 10, 0.7)` (тёмный полупрозрачный)
- **Hover эффект:** Уменьшение непрозрачности до 50%
- **Плавность перехода:** 500ms

## 🎯 Интерактивность

### Hover эффекты

**Для каждой половины:**
1. **Затемнение фона** - overlay становится прозрачнее
2. **Увеличение иконки** - масштаб 1.1x за 500ms
3. **Изменение цвета заголовка** - на золотой (`var(--c-gold)`)
4. **Появление стрелки** - "Перейти в каталог →"

### Кликабельные области

**Левая половина (50% ширины):**
- **Ссылка:** `/catalog?category=forged`
- **Иконка:** 🔨 (молот)
- **Заголовок:** "Кованые изделия"
- **Подзаголовок:** Количество видов и подкатегорий
- **Кнопка:** "Перейти в каталог →"

**Правая половина (50% ширины):**
- **Ссылка:** `/catalog?category=brass`
- **Иконка:** ✨ (блёстки)
- **Заголовок:** "Латунная фурнитура"
- **Подзаголовок:** Количество категорий и подкатегорий
- **Кнопка:** "Перейти в каталог →"
