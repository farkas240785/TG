## Доступ к панели

Панель управления доступна только для пользователей с ролью **manager**.

### Вход в систему

1. Перейдите на страницу входа: `/login`
2. Используйте учётные данные менеджера:
   - **Email:** `manager@tigelgorn.ru`
   - **Пароль:** `manager123`

### Переход в панель управления

После входа в систему:

**Способ 1:** Через Dashboard
- Перейдите в личный кабинет (`/dashboard`)
- Найдите карточку **"🛠️ Панель управления"**
- Нажмите на неё для перехода

**Способ 2:** Прямая ссылка
- Перейдите по адресу: `/admin`

## 📋 Разделы панели управления

### 1. 🏠 Главный экран (Hero)

Редактирование контента первого экрана сайта:

- **Подзаголовок** - текст над заголовком (например, "Литейно-кузнечная мануфактура · Чебоксары · с 2014 года")
- **Заголовок** - основной заголовок (например, "Историческая фурнитура. по нормативам КГИОП")
- **Описание** - текст под заголовком

### 2. 📊 Статистика

Редактирование блока со статистикой (4 показателя):

Для каждого показателя можно изменить:
- **Число** - числовое значение (например, "12+", "47", "4", "100%")
- **Название** - заголовок показателя (например, "лет специализации")
- **Подпись** - дополнительное описание (например, "на объектах ОКН")

### 3. 📜 Манифест

Редактирование манифеста на странице "О нас":

- **Основной текст** - основной текст манифеста
- **Акцент** - выделенная золотым цветом часть текста

### 4. 🔨 О мануфактуре

Редактирование двух блоков "Тигель" и "Горн":

Для каждого блока:
- **Заголовок** - название блока (например, "Металлургия и точность")
- **Описание** - текст описания
- **URL изображения** - ссылка на изображение блока

### 5. 📋 Методология

Редактирование 7 шагов методологии:

Для каждого шага:
- **Номер** - римская цифра (I, II, III...)
- **Название** - заголовок шага
- **Описание** - краткое описание шага

### 6. 🏆 Благодарности

Редактирование блока благодарственных писем:

Для каждого письма:
- **Название организации** - кому адресована благодарность
- **Описание** - за что благодарят
- **URL изображения** - ссылка на изображение письма

### 7. 📞 Контакты

Редактирование контактной информации:

- **Регион** - название региона (например, "Чувашская Республика")
- **Город** - название города (например, "Чебоксары")
- **Адрес** - полный адрес
- **Телефон** - контактный телефон
- **Email** - контактный email
- **Часы работы** - режим работы (каждая строка отдельно)

### 8. 📄 Реквизиты

Редактирование юридических реквизитов:

- **Название** - полное название организации
- **ИНН** - идентификационный номер налогоплательщика
- **КПП** - код причины постановки на учёт
- **ОГРН** - основной государственный регистрационный номер

## 💾 Сохранение изменений

- Все изменения **сохраняются автоматически** при редактировании
- Данные хранятся в **localStorage** браузера
- После изменения появится уведомление **"✓ Изменения сохранены"**
- Изменения сразу отражаются на сайте

---

## 🔄 Сброс изменений

Если нужно вернуть все настройки к значениям по умолчанию:

1. Нажмите кнопку **"Сбросить всё"** в правом верхнем углу панели
2. Подтвердите действие в диалоговом окне
3. Все изменения будут удалены, контент вернётся к исходному состоянию

## 🎯 Особенности работы

### Автоматическое сохранение
- Изменения сохраняются мгновенно при редактировании
- Не нужно нажимать кнопку "Сохранить"
- Данные сохраняются в localStorage браузера

### Предпросмотр
- Изменения сразу видны на сайте
- Можно открыть сайт в новой вкладке (`/`) для проверки

### Ограничения доступа
- Панель управления доступна **только менеджерам**
- Другие роли (architect, customer, technologist) не имеют доступа
- При попытке доступа появится сообщение "Доступ запрещён"

## 🔧 Технические детали

### Хранение данных

- Все данные хранятся в **localStorage** под ключом `site_content`
- Структура данных соответствует интерфейсу `SiteContent`
- При первом запуске используются значения по умолчанию

### Контекст React

- Используется `SiteContentContext` для управления состоянием
- Хук `useSiteContent()` предоставляет доступ к контенту и методам обновления
- Провайдер `SiteContentProvider` оборачивает всё приложение

### Методы API

```typescript
// Получить текущий контент
const { content } = useSiteContent();

// Обновить раздел
updateContent('hero', { title: 'Новый заголовок' });

// Сбросить все изменения
resetContent();
```

---

## ⚠️ Важные замечания

1. **Локальное хранение** - изменения сохраняются только в браузере, где они были сделаны
2. **Очистка кэша** - при очистке кэша браузера изменения будут потеряны
3. **Другие устройства** - изменения не синхронизируются между устройствами
4. **Резервное копирование** - рекомендуется периодически экспортировать настройки
