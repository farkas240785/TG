## 📋 Все разделы панели управления (17 разделов)

### 🏠 1. Главный экран (Hero)
Редактирование первого экрана сайта:
- **Подзаголовок** - текст над заголовком
- **Заголовок** - основной заголовок
- **Описание** - текст под заголовком
- **URL фонового изображения** - фоновое изображение hero-секции

### 📊 2. Статистика
Блок с 4 показателями на главной странице:
- **Число** - числовое значение (например, "12+")
- **Название** - заголовок показателя
- **Подпись** - дополнительное описание

### 📦 3. Каталог
Полное редактирование каталога изделий (8 товаров):
- Артикул, название, тип, материал
- Сплав, вес, габариты
- Покрытие, крепление, статус
- Эпоха, источник, ГОСТ
- Описание и URL изображения

### 🏛️ 4. Проекты
Редактирование 4 реализованных проектов:
- ID, название объекта, адрес
- Статус ОКН, год выполнения
- Задача проекта
- URL изображений: обложка, до/процесс/после
- Номер письма КГИОП

### 💬 5. Обсудить проект
Секция "Обсудить проект" на главной:
- **Заголовок** - название секции
- **Описание** - текст приглашения

### 📜 6. Манифест

### 🔨 7. О мануфактуре

## 💾 Как работает сохранение

- **Автоматическое сохранение** - изменения сохраняются мгновенно
- **localStorage** - данные хранятся в браузере пользователя
- **Уведомление** - появляется сообщение "✓ Изменения сохранены"
- **Мгновенное применение** - изменения сразу видны на сайте

---

## 🔄 Сброс настроек

Кнопка **"Сбросить всё"** в правом верхнем углу:
- Удаляет все изменения из localStorage
- Возвращает контент к значениям по умолчанию
- Требует подтверждения

## 🎯 Особенности работы

### Для каждого раздела:
- Все поля редактируются напрямую
- Изменения применяются мгновенно
- Можно открыть сайт в новой вкладке для проверки
- Данные сохраняются локально в браузере

### Ограничения:
- Доступ только для менеджеров
- Данные хранятся локально (не на сервере)
- При очистке кэша браузера изменения теряются
- Изменения не синхронизируются между устройствами

## 🔧 Техническая информация

### Структура данных:
```typescript
interface SiteContent {
  hero: { subtitle, title, description, heroImage }
  stats: Array<{ num, label, sub }>
  contacts: { city, region, address, phone, email, schedule, mapImage }
  requisites: { name, inn, kpp, ogrn }
  manifesto: { text, accent }
  aboutBlocks: Array<{ title, heading, description, imageUrl }>
  steps: Array<{ step, title, desc }>
  thanks: Array<{ title, description, imageUrl }>
  catalog: Array<{ id, title, type, material, alloy, ... }>
  projects: Array<{ id, object, address, year, task, ... }>
  discuss: { title, description, image }
  footer: { description }
  header: { subtitle }
  aiAssistant: { greeting, name, role }
  docs: { title, description, sections }
  orderForm: { title, description, customerTypes, projectTypes }
  terms: { title, date, sections }
}
```

### Хранение:
- Ключ в localStorage: `site_content`
- Формат: JSON
- Автоматическая загрузка при старте приложения
- Автоматическое сохранение при каждом изменении

---

## ⚠️ Важные замечания

1. **Локальное хранение** - изменения видны только в вашем браузере
2. **Очистка кэша** - удалит все изменения
3. **Другие устройства** - изменения не синхронизируются
4. **Резервное копирование** - экспортируйте настройки вручную при необходимости
5. **Тестирование** - проверяйте изменения на всех страницах
