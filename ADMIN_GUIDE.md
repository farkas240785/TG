## 🖼️ Загрузка изображений

Все поля с изображениями поддерживают **два способа** добавления:

### Способ 1: Загрузка файла
1. Нажмите кнопку **"📁 Загрузить файл"**
2. Выберите изображение с компьютера
3. Поддерживаемые форматы: JPEG, PNG, WebP, GIF
4. Максимальный размер: 2MB
5. Изображение автоматически конвертируется в base64 и сохраняется

### Способ 2: Указание URL
1. Вставьте ссылку на изображение в текстовое поле
2. Изображение будет загружаться по URL при каждом посещении сайта

### Преимущества загрузки файла:
- ✅ Изображение сохраняется локально
- ✅ Не зависит от внешних сервисов
- ✅ Быстрая загрузка на сайте
- ✅ Можно просмотреть превью

### Ограничения:
- ⚠️ Максимальный размер файла: 2MB
- ⚠️ Общий размер localStorage: ~5MB
- ⚠️ Изображения видны только в вашем браузере
- ⚠️ При очистке кэша загруженные изображения удалятся

### Управление загруженными изображениями:
- **👁 Показать/Скрыть** - просмотр превью изображения
- **Очистить** - удалить изображение
- Можно переключаться между загрузкой файла и URL

## 🔧 Техническая информация

### Структура данных:
```typescript
interface SiteContent {
  hero: { subtitle, title, description, heroImage }
  stats: Array<{ num, label, sub }>
  contacts: { city, region, address, phone, email, schedule, mapImage }
  requisites: { name, inn, kpp, ogrn }
  manifesto: { text, accent }
  aboutBlocks: Array<{ title, heading, description, imageUrl }>
  steps: Array<{ step, title, desc }>
  thanks: Array<{ title, description, imageUrl }>
  catalog: Array<{ 
    id, title, type, 
    category: 'forged' | 'brass',
    subcategory: string, // Подкатегория
    material, alloy, ... 
  }>
  projects: Array<{ id, object, address, year, task, ... }>
  discuss: { title, description, image }
  footer: { description }
  header: { subtitle }
  aiAssistant: { greeting, name, role }
  docs: { title, description, sections }
  orderForm: { title, description, customerTypes, projectTypes }
  terms: { title, date, sections }
}
```

### Хранение:
- Ключ в localStorage: `site_content`
- Формат: JSON
- Автоматическая загрузка при старте приложения
- Автоматическое сохранение при каждом изменении
- Загруженные изображения хранятся в формате base64 (data URL)

### Загрузка изображений:
- Компонент: `ImageUploader.tsx`
- Утилита: `utils/imageUpload.ts`
- Конвертация: FileReader API → base64
- Валидация: тип файла, размер (макс. 2MB)
- Проверка квоты localStorage перед сохранением
- Превью загруженных изображений

### Категории каталога:
- **Кованые изделия** (`forged`) - петли, решётки, скобы
- **Латунная фурнитура** (`brass`) - ручки, шпингалеты, наличники, накладки

### Подкатегории латунной фурнитуры:
- **Оконные приборы** (`window-fittings`) - кремоны, задвижки, фиксаторы, вентиляция
- **Дверные приборы** (`door-fittings`) - ручки, кнобы, засовы, ключевины, молотки, упоры
- **Петли и навесы** (`hinges`) - карточные, ввертные, скрытые
- **Мебельные элементы** (`furniture-fittings`) - ручки, декор, каминные приборы
- **Архитектурная фурнитура** (`architectural-fittings`) - решётки, ковродержатели, кронштейны

## ⚠️ Важные замечания

1. **Локальное хранение** - изменения видны только в вашем браузере
2. **Очистка кэша** - удалит все изменения, включая загруженные изображения
3. **Другие устройства** - изменения не синхронизируются
4. **Резервное копирование** - экспортируйте настройки вручную при необходимости
5. **Тестирование** - проверяйте изменения на всех страницах
6. **Загруженные изображения** - хранятся в base64 в localStorage (лимит ~5MB)
7. **Размер файлов** - максимальный размер загружаемого изображения 2MB
8. **Форматы** - поддерживаются JPEG, PNG, WebP, GIF
