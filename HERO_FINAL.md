## 📊 Технические характеристики

### Параметры изображения
- **Размер:** 1920×1080 px (Full HD)
- **Соотношение:** 16:9
- **Формат:** PNG
- **Стиль:** Split-composition, профессиональная фотография

### Применение в коде
```tsx
<img 
  src={content.hero.heroImage} 
  alt="Мастерская" 
  className="w-full h-full object-cover opacity-40" 
  style={{ filter: 'brightness(0.5) contrast(1.1)' }} 
/>
```

### Эффекты
- **opacity: 40%** — полупрозрачность для читаемости текста
- **brightness: 0.5** — затемнение для контраста
- **contrast: 1.1** — усиление детализации
- **backdrop-filter: blur(2px)** — легкое размытие фона

### Overlay
```tsx
<div style={{ 
  background: 'linear-gradient(to right, rgba(8, 7, 10, 0.98) 0%, rgba(8, 7, 10, 0.4) 50%, rgba(8, 7, 10, 0.2) 100%)',
  backdropFilter: 'blur(2px)'
}}></div>
```

**Эффект:**
- Левая сторона: почти полностью затемнена (98% opacity)
- Центр: умеренное затемнение (40% opacity)
- Правая сторона: легкое затемнение (20% opacity)
- Создает градиент для лучшей читаемости текста
