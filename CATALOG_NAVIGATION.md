# 🧭 Система навигации по каталогу

## Обзор

Каталог исторической фурнитуры использует многоуровневую систему навигации, позволяющую пользователям удобно перемещаться между категориями и подкатегориями товаров.

---

## 📊 Структура каталога

### Уровень 1: Основные категории

Каталог разделён на две основные категории:

#### 🔨 **Кованые изделия** (10 товаров)
Изделия из стали, изготовленные методом художественной ковки.

**Вид 1: Оконная фурнитура и приборы** 🪟

**Подвид 1.1: Запирающие механизмы и приборы** (locking-mechanisms)
- FG-W-001: Кремона раздвижная двуштанговая
- FG-W-002: Шпингалет рычажный с граненым штоком
- FG-W-003: Завертка оконная Т-образная

**Подвид 1.2: Опорные и связующие элементы** (support-elements)
- FG-W-004: Жиковина угловая просечная

**Подвид 1.3: Элементы фиксации и наружной защиты** (fixation-protection)
- FG-W-005: Крючок ветровой оконный

**Вид 2: Дверная фурнитура и приборы** 🚪

**Подвид 2.1: Дверные навесы (Петли)** (door-hinges)
- FG-D-001: Жиковина стреловидная с трилистником

**Подвид 2.2: Приводы запорных механизмов (Ручки)** (door-handles)
- FG-D-002: Ручка-кольцо из гнутого прута
- FG-D-003: Ручка-скоба витая с торшонированием

**Подвид 2.3: Замки, ключевины и крепежные элементы** (locks-keys)
- FG-D-004: Накладка замочная прорезная

**Подвид 2.4: Вспомогательные запорные элементы дверей** (door-bolts)
- FG-D-005: Засов дверной полосовой

#### ✨ **Латунная фурнитура** (5 товаров)
Изделия из латуни, изготовленные методом литья.

**Основные группы (5 категорий):**

1. **🪟 Оконные латунные приборы** (window-fittings)
   - Кремоны и эспаньолеты
   - Оконные задвижки
   - Форточные и фрамужные фиксаторы
   - Вентиляционные приборы

2. **🚪 Дверные латунные приборы** (door-fittings)
   - Дверные ручки
   - Ручки-кнобы
   - Дверные засовы
   - Ключевины
   - Дверные молотки
   - Дверные упоры

3. **🔩 Петли и навесы** (hinges)
   - Петли карточные
   - Петли ввертные и скрытые

4. **🪑 Мебельные и интерьерные элементы** (furniture-fittings)
   - Мебельные ручки
   - Накладной декор
   - Каминные приборы

5. **🏛️ Архитектурная фурнитура** (architectural-fittings)
   - Вентиляционные решётки
   - Ковродержатели
   - Кронштейны перил

## 🧭 Элементы навигации

### 1. Хлебные крошки (Breadcrumbs)

Расположены под заголовком страницы. Показывают текущий путь пользователя.

**Примеры:**
```
Все изделия
Все изделия / Кованые изделия
Все изделия / Латунная фурнитура / Дверные ручки
```

**Функциональность:**
- Клик по любому элементу возвращает на соответствующий уровень
- Последний элемент (текущая страница) не является ссылкой
- Разделитель: `/` золотого цвета

---

### 2. Навигационные табы

Расположены под хлебными крошками. Позволяют быстро переключаться между категориями.

**Основные табы:**
- **Все** — показать все товары (счётчик: 15)
- **🔨 Кованые** — показать только кованые изделия (счётчик: 10)
- **✨ Латунные** — показать только латунную фурнитуру (счётчик: 5)

**Табы подкатегорий:**
Появляются при выборе основной категории.

**Для латунной фурнитуры:**
- 🪟 Оконные (счётчик)
- 🚪 Дверные (счётчик)
- 🔩 Петли (счётчик)
- 🪑 Мебельные (счётчик)
- 🏛️ Архитектурные (счётчик)

**Для кованых изделий:**
- 🪟 Оконная фурнитура (счётчик)
- 🚪 Дверная фурнитура (счётчик)

**Визуальное состояние:**
- Активный таб: золотой фон, тёмный текст
- Неактивный таб: прозрачный фон, серый текст
- При наведении: текст становится светлее

---

### 3. Статистика

Расположена под заголовком страницы. Показывает общую информацию о каталоге.

**Отображаемые данные:**
```
Всего: 15 изделий
Кованые: 10
Латунные: 5
Показано: 10 (при активной фильтрации)
```

---

### 4. Панель управления

Расположена под навигационными табами. Содержит инструменты для работы с каталогом.

#### 🔍 Локальный поиск
- Поле ввода с placeholder: "Поиск по каталогу..."
- Поиск работает в реальном времени
- Ищет по: артикулу, названию, описанию, сплаву
- Не требует нажатия Enter

#### 🔄 Сортировка
Выпадающий список с вариантами:
- **По умолчанию** — порядок из базы данных
- **По названию** — алфавитный порядок (A-Я)
- **По артикулу** — порядок по ID товара

#### 👁️ Переключение вида
Две кнопки для переключения между режимами отображения:

**Сетка (Grid):**
- Карточки в сетке 4 колонки (на больших экранах)
- Компактное отображение
- Удобно для быстрого обзора

**Список (List):**
- Горизонтальные карточки
- Больше информации видно сразу
- Удобно для детального сравнения

---

### 5. Группировка товаров

Товары отображаются сгруппированными по подкатегориям с заголовками.

**Формат заголовка группы:**
```
🔩 Петли карточные (1)
```

**Элементы заголовка:**
- Иконка подкатегории (эмодзи)
- Название подкатегории
- Счётчик товаров в группе

**Разделение групп:**
- Каждая группа отделена горизонтальной линией
- Отступ между группами: 48px

## 🎯 Сценарии навигации

### Сценарий 1: Просмотр всех товаров

1. Пользователь переходит на `/catalog`
2. Видит все товары, сгруппированные по основным категориям:
   - 🔨 Кованые изделия (10 товаров)
   - ✨ Латунная фурнитура (5 товаров)
3. Каждая группа показывает первые 4 товара (в режиме сетки)
4. Ссылка "Показать все →" ведёт на полную версию категории

### Сценарий 2: Выбор категории

1. Пользователь нажимает таб **"🔨 Кованые"**
2. URL меняется на `/catalog?category=forged`
3. Появляются табы подкатегорий: 🪟 Оконная фурнитура, 🚪 Дверная фурнитура
4. Товары фильтруются по категории
5. Хлебные крошки обновляются: `Все изделия / Кованые изделия`

### Сценарий 3: Выбор подкатегории

1. Пользователь находится в категории "Латунная фурнитура"
2. Нажимает таб **"🚪 Дверные"**
3. URL меняется на `/catalog?category=brass&subcategory=door-handles`
4. Показываются только товары из подкатегории "Дверные ручки"
5. Хлебные крошки: `Все изделия / Латунная фурнитура / Дверные ручки`

### Сценарий 4: Поиск товара

1. Пользователь вводит "ручка" в поле поиска
2. Результаты фильтруются в реальном времени
3. Показываются только товары, содержащие "ручка" в названии, описании или артикуле
4. Счётчик "Показано" обновляется

### Сценарий 5: Возврат назад

1. Пользователь находится в подкатегории
2. Нажимает на хлебную крошку "Латунная фурнитура"
3. URL меняется на `/catalog?category=brass`
4. Показываются все товары категории
5. Табы подкатегорий остаются видимыми

## 🔗 URL-параметры

Навигация управляется через URL-параметры:

### `category`
Основная категория товара.
- `forged` — кованые изделия
- `brass` — латунная фурнитура

**Пример:** `/catalog?category=forged`

### `subcategory`
Подкатегория товара.
- Для кованых: `locking-mechanisms`, `support-elements`, `fixation-protection`, `door-hinges`, `door-handles`, `locks-keys`, `door-bolts`
- Для латунных: `door-handles`, `window-bolts`, `keyholes` и т.д.

**Пример:** `/catalog?category=brass&subcategory=door-handles`
**Пример:** `/catalog?category=forged&subcategory=locking-mechanisms`

### `type`
Тип изделия (дополнительный фильтр).
- `handles` — ручки
- `hinges` — петли
- `grilles` — решётки
- и т.д.

**Пример:** `/catalog?type=handles`

### Комбинированные параметры
Можно комбинировать несколько параметров:

**Пример:** `/catalog?category=brass&subcategory=door-handles&type=handles`

## 🎨 Визуальные состояния

### Активная категория
- Таб имеет золотой фон (`var(--c-gold)`)
- Текст тёмный (`var(--c-coal)`)
- Граница отсутствует

### Неактивная категория
- Таб прозрачный
- Текст серый (`var(--c-ash)`)
- Граница: `1px solid var(--c-rule-light)`
- При наведении текст становится светлее

### Активная подкатегория
- Таб имеет тёмно-золотой фон (`var(--c-gold-deep)`)
- Текст тёмный (`var(--c-coal)`)

### Хлебные крошки
- Ссылки: серый цвет, при наведении — золотой
- Текущая страница: светлый цвет, не является ссылкой
- Разделитель `/`: золотой цвет

## 📱 Адаптивность

### Десктоп (≥1280px)
- Сетка: 4 колонки
- Табы в одну строку
- Панель управления в одну строку

### Планшет (768px - 1279px)
- Сетка: 3 колонки
- Табы могут переноситься на новую строку
- Панель управления в две строки

### Мобильный (< 768px)
- Сетка: 2 колонки
- Табы в несколько строк
- Панель управления вертикально
- Хлебные крошки могут переноситься

## 💡 Советы по использованию

1. **Используйте хлебные крошки** для быстрого возврата на уровень выше
2. **Обращайте внимание на счётчики** в табах — они показывают количество товаров
3. **Переключайте вид отображения** (сетка/список) для удобства
4. **Используйте сортировку** для быстрого поиска нужного товара
5. **Локальный поиск** работает мгновенно — не нужно нажимать Enter
6. **Комбинируйте фильтры** через URL для точного выбора

## 🔧 Техническая реализация

### Компоненты

**Catalog.tsx** — основной компонент каталога
- Управление состоянием фильтров
- Группировка товаров
- Рендеринг навигационных элементов

**ProductCard** — компонент карточки товара
- Поддержка двух режимов отображения (grid/list)
- Hover-эффекты
- Адаптивная вёрстка

### Функции

**filterProducts()** — фильтрация товаров
- Поддержка множественных фильтров
- Работа с двухуровневой структурой

**getAllBrassSubcategories()** — получение всех подкатегорий латунной фурнитуры
- Возвращает плоский список всех подкатегорий
- Содержит информацию о родительской категории

**getAllForgedSubcategories()** — получение всех подкатегорий кованых изделий
- Возвращает плоский список всех подкатегорий
- Содержит информацию о родительской категории (Вид 1/Вид 2)

**getSubcategoryName()** — получение названия подкатегории
- Поддержка обеих категорий (кованые/латунные)
- Возврат человекочитаемого названия

### Структуры данных

**forgedCategories** — иерархия кованых изделий
- Вид 1: Оконная фурнитура и приборы
  - Подвид 1.1: Запирающие механизмы и приборы
  - Подвид 1.2: Опорные и связующие элементы
  - Подвид 1.3: Элементы фиксации и наружной защиты
- Вид 2: Дверная фурнитура и приборы
  - Подвид 2.1: Дверные навесы (Петли)
  - Подвид 2.2: Приводы запорных механизмов (Ручки)
  - Подвид 2.3: Замки, ключевины и крепежные элементы
  - Подвид 2.4: Вспомогательные запорные элементы дверей

**brassCategories** — иерархия латунной фурнитуры
- Оконные латунные приборы
- Дверные латунные приборы
- Петли и навесы
- Мебельные и интерьерные элементы
- Архитектурная фурнитура
