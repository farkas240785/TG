# 🎬 HERO-секция - Анимации

## 📋 Обзор

HERO-секция теперь содержит многослойную анимацию, имитирующую атмосферу литейно-кузнечной мануфактуры с эффектами льющегося металла, искрами от кузнечных работ, свечением горна и дымом.

---

## 🎨 Структура анимаций

### 1. **Расплавленный металл** (`.hero-molten-metal`)

**Эффект:** Плавное движение градиентов, имитирующее текучесть расплавленного металла

**Технические детали:**
- Множественные радиальные градиенты с золотистыми и бронзовыми тонами
- Анимация `molten-flow` (15 секунд, бесконечная)
- Размытие `blur(40px)` для создания эффекта жидкости
- Дополнительные слои через `::before` и `::after`

**Визуальные элементы:**
- Основной слой: движение теплых градиентов
- `::before`: капли расплавленного металла (анимация `metal-drops`)
- `::after`: волны металла (анимация `metal-waves`)

**Цветовая палитра:**
- `rgba(212, 160, 23, 0.15)` - золотистый
- `rgba(184, 134, 11, 0.12)` - бронзовый
- `rgba(139, 105, 20, 0.1)` - темное золото
- `rgba(196, 90, 60, 0.08)` - медный

---

### 2. **Искры от кузнечных работ** (`.hero-sparks`)

**Эффект:** Множественные яркие точки, имитирующие искры от удара молота по раскаленному металлу

**Технические детали:**
- 9 радиальных градиентов разного размера (1-2px)
- Анимация `sparks-fly` (6 секунд, бесконечная)
- Дополнительный слой через `::before` с 4 градиентами
- Режим наложения `mix-blend-mode: screen` для яркости
- Анимация мерцания `flicker` (2 секунды)

**Визуальные элементы:**
- Основной слой: основные искры с движением
- `::before`: вторичные искры с другим timing (9 секунд)
- Мерцание: имитация случайного свечения

**Цветовая палитра:**
- `rgba(232, 197, 71, 0.9)` - яркий золотистый
- `rgba(212, 160, 23, 0.85)` - золотистый
- `rgba(240, 217, 122, 0.95)` - светло-золотистый
- `rgba(184, 134, 11, 0.85)` - бронзовый
- `rgba(196, 90, 60, 0.7)` - медный

---

### 3. **Свечение горна** (`.hero-forge-glow`)

**Эффект:** Пульсирующее теплое свечение, имитирующее жар от кузнечного горна

**Технические детали:**
- 3 радиальных градиента с разными позициями
- Анимация `forge-pulse` (4 секунды, бесконечная)
- Режим наложения `mix-blend-mode: screen`
- Дополнительный слой через `::before` с волнами жара

**Визуальные элементы:**
- Основной слой: пульсирующее свечение с вращением
- `::before`: расходящиеся волны жара (анимация `heat-waves`, 3 секунды)

**Цветовая палитра:**
- `rgba(196, 90, 60, 0.25)` - оранжево-красный (жар)
- `rgba(212, 160, 23, 0.15)` - золотистый
- `rgba(184, 134, 11, 0.12)` - бронзовый

---

### 4. **Дым и пар** (`.hero-smoke`)

**Эффект:** Полупрозрачные слои, имитирующие дым от кузнечных работ

**Технические детали:**
- 3 радиальных градиента с серыми тонами
- Анимация `smoke-rise` (20 секунд, бесконечная)
- Размытие `blur(20px)` для мягкости
- Дополнительный слой через `::before` с анимацией `smoke-drift` (25 секунд)

**Визуальные элементы:**
- Основной слой: поднимающийся дым с вращением
- `::before`: дрейфующий дым с другим timing

**Цветовая палитра:**
- `rgba(107, 101, 96, 0.12)` - светло-серый
- `rgba(107, 101, 96, 0.1)` - серый
- `rgba(61, 58, 54, 0.08)` - темно-серый

## 🎭 Ключевые кадры анимаций

### `molten-flow` (15s)
Движение градиентов расплавленного металла с изменением прозрачности и легким вращением.

### `metal-drops` (10s)
Вертикальное движение капель металла с изменением масштаба.

### `metal-waves` (12s)
Движение волн металла по диагонали с изменением масштаба.

### `sparks-fly` (6s)
Движение искр по диагонали с изменением прозрачности и масштаба.

### `sparks-secondary` (9s)
Вторичное движение искр с другим timing.

### `flicker` (2s)
Случайное мерцание искр с изменением яркости.

### `forge-pulse` (4s)
Пульсация свечения горна с вращением и изменением яркости.

### `heat-waves` (3s)
Расходящиеся волны жара от центра горна.

### `smoke-rise` (20s)
Поднимающийся дым с вращением и изменением прозрачности.

### `smoke-drift` (25s)
Дрейфующий дым с горизонтальным и вертикальным движением.

## ⚡ Производительность

### Оптимизации:
- Использование `transform` и `opacity` для анимаций (GPU-ускорение)
- `will-change` не используется (браузер оптимизирует автоматически)
- Размытие через `filter: blur()` (эффективно для фоновых элементов)
- `mix-blend-mode: screen` для ярких эффектов (быстрее чем `overlay`)

## 🔧 Настройка анимаций

### Изменение скорости:
```css
/* Ускорить движение металла */
.hero-molten-metal {
  animation: molten-flow 10s ease-in-out infinite; /* было 15s */
}

/* Замедлить дым */
.hero-smoke {
  animation: smoke-rise 30s ease-in-out infinite; /* было 20s */
}
```

### Изменение интенсивности:
```css
/* Более яркие искры */
.hero-sparks {
  opacity: 0.9; /* было 0.7 */
}

/* Более заметное свечение горна */
.hero-forge-glow {
  background: radial-gradient(circle at 50% 50%, rgba(196, 90, 60, 0.4) 0%, transparent 60%);
}
```

### Отключение анимаций:
```css
/* Для пользователей с prefers-reduced-motion */
@media (prefers-reduced-motion: reduce) {
  .hero-molten-metal,
  .hero-sparks,
  .hero-forge-glow,
  .hero-smoke {
    animation: none;
  }
}
```
