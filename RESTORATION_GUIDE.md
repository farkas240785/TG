## 📦 Резервное копирование

### Автоматическое резервное копирование

Создайте скрипт `backup.sh`:

```bash
#!/bin/bash

# Дата бэкапа
DATE=$(date +%Y%m%d_%H%M%S)
BACKUP_DIR="backups/backup_$DATE"

# Создать директорию
mkdir -p $BACKUP_DIR

# Копировать файлы
cp -r src $BACKUP_DIR/
cp index.html $BACKUP_DIR/
cp package.json $BACKUP_DIR/
cp tsconfig.json $BACKUP_DIR/
cp vite.config.js $BACKUP_DIR/
cp *.md $BACKUP_DIR/

# Создать архив
tar -czf "backup_$DATE.tar.gz" $BACKUP_DIR

# Удалить временную директорию
rm -rf $BACKUP_DIR

echo "✅ Резервная копия создана: backup_$DATE.tar.gz"
```

### Расписание резервного копирования

Рекомендуется создавать резервные копии:
- **Ежедневно** - перед началом работы
- **После значимых изменений** - добавление новых функций
- **Перед деплоем** - перед публикацией на сервере

### Хранение резервных копий

Рекомендуемые места хранения:
1. **Локально** - папка `backups/`
2. **Облако** - Google Drive, Dropbox, Yandex Disk
3. **Git** - отдельная ветка или теги
4. **Внешний диск** - USB-накопитель

## 🚨 Частые проблемы и решения

### Проблема 1: "Module not found"

**Решение:**
```bash
npm install
npm run build
```

### Проблема 2: Белый экран после сборки

**Решение:**
```bash
# Проверить консоль браузера на ошибки
# Обычно проблема в отсутствии файлов src/
./check-integrity.sh
```

### Проблема 3: Не работает авторизация

**Решение:**
```bash
# Очистить localStorage
# В консоли браузера:
localStorage.clear()

# Перезагрузить страницу
```

### Проблема 4: Изображения не загружаются

**Решение:**
- Проверить интернет-соединение
- Изображения загружаются с image.qwenlm.ai
- Если сервис недоступен - изображения не будут отображаться

### Проблема 5: Панель управления недоступна

**Решение:**
